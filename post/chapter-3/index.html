#003: Apartment Price Prediction in Polish Cities!

January 1, 2025

Apartment Price Prediction in Polish Cities

Project Overview

This project presents an end-to-end Machine Learning solution for predicting apartment prices across major Polish cities. The final model is also integrated into an interactive Streamlit application, allowing users to experiment with parameters and observe how predicted prices change in real time.

Objective

The goal was to build a regression model capable of accurately estimating the market price of an apartment based on variables such as:

  • city,
  • surface area,
  • number of rooms,
  • floor level,
  • building type,
  • year of construction, and more.

The solution supports practical use cases such as real-estate valuation, investment analysis, and automated pricing tools.

Key Skills Demonstrated

  • Advanced data cleaning and preprocessing
  • Business-oriented feature engineering
  • Evaluation and comparison of multiple ML algorithms
  • Model optimization and validation
  • Model explainability through feature importance and visual analysis
  • Clean, organized, and modular Python code
  • Deployment of a Streamlit interactive web app

Workflow Summary

1. Exploratory Data Analysis (EDA)

  • Analyzed distributions, outliers, and correlations
  • Compared price structures between cities
  • Identified and handled missing or inconsistent values
  • Visualized key relationships driving price differences

2. Feature Engineering

Created and transformed features to improve predictive performance, including:

  • building age,
  • price per square meter,
  • room-to-area ratio,
  • encoding of categorical variables,
  • structural features such as floor level and building type.

3. Model Development

Several regression models were trained and compared, including:

  • Linear Regression
  • Ridge/Lasso
  • Random Forest Regressor
  • Gradient Boosting models

Models were evaluated using MAE, RMSE, and R², ensuring both accuracy and generalization.

4. Model Interpretation

To ensure transparency and business usability, the project includes:

  • feature importance analysis,
  • interpretation of variable impact on prices,
  • insights into market differences across cities.

Interactive Streamlit Application

I built a dedicated Streamlit app to make the model accessible for real-time exploration:

🔗 https://apartmentpriceprediction.streamlit.app/

The app allows users to:

  • modify apartment features (city, size, rooms, floor, etc.),
  • instantly see updated predicted prices,
  • understand how individual parameters influence the result.

This demonstrates practical model deployment and user experience design—important skills for a mid-level Data Scientist.

Results

The final model provides reliable price predictions and clearly highlights the most influential factors. The accompanying application creates a hands-on tool for exploring real-estate pricing dynamics, making the project valuable both technically and from a business perspective.

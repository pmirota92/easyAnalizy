#003: Apartment Price Prediction in Polish Cities!

January 1, 2025

Property Price Prediction Using XGBoost & Model Optimization

Business Objective: Developed a regression model to predict Apartment Price in order to support [business impact, e.g., pricing strategy, forecasting accuracy, operational decision-making].

Data & Feature Engineering:

Processed 122 873 records with 9 features. Key features: squareMeters, rooms, buildYear, collegeDistance, centreDistance, floorCount, poiCount, hasElevator, city.

Implemented:

  • rigorous EDA (distribution analysis, target leakage checks, feature–target relationships),
  • outlier treatment using box plots,
  • removed outliers using the IQR method to prevent extreme values from distorting model performance.,
  • feature transformations: new variables (‘age_of_building’) are created to enhance model performance, and categorical features are encoded,
  • multicollinearity diagnostics (correlation thresholds).

Modeling Strategy:

Established a comparative pipeline evaluating Linear Regression vs. XGBoost. Used GridSearchCV with cross-validation (k = 5) to systematically optimize key hyperparameters. Assessment focused on generalization performance, stability across folds, and error variance.

Model Choice Rationale:

XGBoost was selected due to:

  • superior handling of non-linearities,
  • robustness to outliers,
  • reduced RMSE and MAE across CV splits,
  • stronger feature interaction modeling,
  • better residual distribution and lower error heteroscedasticity.

Linear Regression served as a strong interpretable baseline, confirming linear components in the data.

Optimized Hyperparameters (GridSearchCV):

  • learning_rate = 0.1
  • max_depth = 10
  • n_estimators = 200
  • subsample = 0.8
  • colsample_bytree = 1.0

Results & Performance:

  • Linear Regression R² Score: 0.45
  • XGBoost RMSE: 72 038
  • XGBoost MAE: 49 247
  • R² Score: 0.93
  • CV variance: [low/medium] — indicating strong generalization.
  • Residuals displayed [desired pattern — e.g., near-zero mean, reduced heteroscedasticity].

Model Explainability & Insights:

Applied SHAP for interpretability at global and local levels. The strongest predictive drivers were:

  • city_encoded 0.90
  • squareMeters 0.75
  • age_of_building 0.28

Tech Stack:

Python, Scikit-Learn, XGBoost, Pandas, NumPy, Matplotlib, SHAP, Seaborn.

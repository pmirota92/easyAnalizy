#001: Oil Diagnostics – End-to-End Machine Learning Pipeline for Oil Condition Classification

November 2, 2024

Objective: Built a complete analytical and predictive system for classifying industrial oil samples into operational states (A, B, C, X) based on particle-count distributions, chemical composition, and ISO cleanliness metrics. Delivered an end-to-end solution including preprocessing, modeling, explainability, class imbalance handling, and a fully interactive Streamlit application.

Data Understanding & Domain-Driven Preprocessing

Processed a laboratory dataset containing 40+ contamination, chemistry, and ISO cleanliness measurements. Addressed several real-world industrial data challenges:

  • Converted domain-specific noise such as "<1" (below detection limits) into valid numeric values through a custom transformation pipeline.
  • Imputed missing particle-size counts (X-prefix variables) using median substitution after stability checks.
  • Removed near-zero variance chemistry variables to reduce noise.
  • Automatically type-cast numerical columns to ensure a stable and reproducible schema.
  • Performed deep EDA including distribution analysis, correlation mapping, missingness profiling, and identification of highly correlated particle-size ranges.

This ensured the data was modeling-ready and aligned with domain expectations.

Feature Engineering & Dimensionality Reduction

  • One-hot encoded categorical identifiers.
  • Removed non-informative or redundant variables (dates, IDs, empty chemistry columns).
  • Applied model-based feature selection (SelectFromModel with RandomForest) using an importance threshold of 0.03, isolating the most predictive subset of variables.
  • Reduced dimensionality significantly while preserving—and in some cases improving—model generalization.

Machine Learning Approach & Model Diagnostics

Selected a Random Forest Classifier due to its robustness to noise, ability to model non-linear patterns.

  • Performed cross-validated hyperparameter tuning (tree depth analysis up to depth=10).
  • Chose depth = 7 based on accuracy stability across folds.
  • Used stratified splitting to preserve minority contamination categories.
  • Assessed model performance using accuracy, macro-F1, confusion matrices, and detailed class-level diagnostics.

Identified class X as a rare and difficult class to predict, prompting dedicated imbalance handling.

Handling Class Imbalance (SMOTE)

To improve detection of critical “X” contamination samples:

  • Applied SMOTE (k=1) for synthetic minority oversampling.
  • Retrained the classifier on the rebalanced dataset.
  • Observed substantial improvement in recall and macro-F1 for previously underrepresented classes.

Model Explainability & Insights

To improve transparency and support decision-making:

  • Computed permutation importance for global feature ranking.
  • Applied model-based feature thresholding for focused interpretability.
  • Analyzed misclassifications and variable interactions affecting degradation state assignments.

This enabled meaningful interpretation of contamination drivers rather than treating the model as a black box.

Deployment – Real-Time Interactive Streamlit Application

Developed a fully interactive Streamlit application providing:

  • Data exploration (missingness, distributions, correlation metrics)
  • Automated preprocessing pipeline (cleaning, encoding, imputation)
  • On-demand model training and evaluation
  • Real-time oil-state predictions using user-provided or randomly generated samples
  • Conversion of predicted labels into domain-readable oil condition categories (A/B/C/X)

The app enables maintenance engineers to explore data trends and obtain immediate diagnostic predictions—without programming skills.

#001: OIL TYPES PREDICTION

November 2, 2024

Oil Analysis & Classification – Advanced End-to-End Machine Learning System

This project implements a complete analytical and predictive pipeline for industrial oil diagnostics using particle-count distributions, chemical composition, and ISO cleanliness measures. It demonstrates advanced data preprocessing, exploratory analysis, imbalanced learning, model optimization, feature selection, and interactive deployment through Streamlit. The goal is to classify oil samples into operational states (A, B, C, X) and provide interpretable, real-time predictions for maintenance engineers.

1. Data Understanding & Domain-Driven Preprocessing

The dataset contains 40+ laboratory variables describing contamination levels, elemental composition, viscosity, machine runtime, and ISO particle cleanliness metrics. Several real-world challenges were addressed:

Handling domain-specific non-numeric noise

  • Many chemical composition columns contain values like "<1" (detection limits).
  • A custom transformation pipeline replaced these with 0, preserving monotonicity while avoiding artificial inflation of trace elements.

High missingness in particle-size distributions

  • All X-prefixed columns (~16% missing) reflect sensor instability at specific particle diameters.
  • Missing values were imputed using median substitution, after verifying stationarity across measurement ranges.
  • Fully empty chemistry columns (“BO3”, “PO4”, “F”) were removed based on near-zero variance analysis.

Automatic numeric conversion

  • Object-type columns were programmatically converted to integers only when safe, ensuring schema stability.

Deep Exploratory Data Analysis

The app integrates interactive diagnostics:

  • Missing value matrices (missingno)
  • Distribution analysis (histograms, boxplots)
  • Correlation heatmaps using Plotly
  • Data type profiling This allowed the identification of:
  • heavy-tailed variables (Fe, PQI, ISO counts),
  • multimodal contamination indicators,
  • strong collinearity between particle sizes (X6–X70),
  • seasonality in machine-hour-related attributes.

2. Feature Engineering & Variable Reduction

Based on exploratory insights and model interpretability considerations:

  • Categorical oiltypeid was one-hot encoded.
  • Non-informative variables (sampledate, oilgradeid, “PO4”, “BO3”, “Sn”, “F”) were removed.
  • Additional dynamic feature selection was performed using SelectFromModel(RandomForest) with a threshold of 0.03, automatically isolating features contributing meaningful predictive signal.

This reduced dimensionality significantly, lowering model complexity and improving generalization.

3. Machine Learning Approach: Random Forest + Model Diagnostics

A Random Forest Classifier was chosen due to:

  • robustness to noisy, high-dimensional lab data,
  • resistance to multicollinearity,
  • ability to model non-linear interactions between contamination metrics,
  • interpretability via feature importance.

Model selection & tuning

  • Evaluated tree depth from 1–10 against cross-validated accuracy curves.
  • Identified depth = 7 as optimal based on cross-validation stability.
  • Performed stratified train/test splitting to preserve rare classes.

Performance Evaluation

  • Achieved stable accuracy across folds.
  • Generated classification reports for precision, recall, and F1 per oil class (A, B, C, X).
  • Identified weaknesses in predicting minority class X, leading to the next improvement step.

4. Handling Class Imbalance With SMOTE

The X-class (critical contamination) was extremely underrepresented. To ensure the model can correctly detect hazardous samples:

  • Applied SMOTE (k=1) to synthetically generate realistic minority-class observations.
  • Retrained RandomForest on the resampled distribution.
  • Evaluated the uplift in recall and macro-F1 after resampling.

This step significantly improved model robustness, particularly for critical outlier cases.

5. Feature Selection Using Model-Based Thresholding

To build a more interpretable and deployment-ready model:

  • Applied SelectFromModel using the base RandomForest estimator.
  • Used an importance threshold of 0.03, keeping only the most informative variables.
  • Retrained the model on the reduced feature space while maintaining predictive performance.

This resulted in:

  • lower dimensionality,
  • faster inference,
  • more stable generalization,
  • clear reasoning about which oil properties drive degradation states.

6. Real-Time Interactive Deployment through Streamlit

A fully interactive web application was developed with:

  • Dataset exploration (types, distributions, missingness)
  • Custom EDA visualizations (Plotly, Matplotlib)
  • Automated preprocessing pipeline (data cleaning, encoding, imputation)
  • Toggle-enabled advanced plots
  • Model training and evaluation directly inside the interface
  • Real-time prediction using user-generated or random sample inputs

The prediction module:

  • Generates feature inputs dynamically within observed variable ranges
  • Uses the optimized and feature-reduced RandomForest model
  • Converts numeric label predictions back to human-readable oil states (A/B/C/X)

This ensures the solution is accessible to maintenance teams without Python expertise.

7. Project Impact & Technical Value

This project demonstrates:

  • End-to-end DS workflow: raw data → cleaning → EDA → modeling → evaluation → deployment
  • Advanced preprocessing logic for industrial lab datasets
  • Modeling of imbalanced multi-class classification
  • Feature selection based on model interpretability
  • Robust deployment with Streamlit UI
  • Integration of multiple libraries (Plotly, missingno, SMOTE, RF, EDA tools)
  • Production-minded thinking: reproducibility, schema checks, user input validation
